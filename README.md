# AI Buddy Group

用于按用户分组管理 AI Buddy 资源策略，并控制服务商、模型、MCP、专家、知识库和技能的可见范围

## 插件类型

- 应用级插件

## 配置说明

当前插件无需额外配置

## 使用方式

1. 安装并启用 AI Buddy 插件和本插件后重启后端服务
2. 创建 AI 分组并填写分组名称和分组描述
3. 为分组绑定系统用户
4. 在分组资源配置中，按服务商、模型、MCP、专家、知识库和技能分别设置全部可见、全部不可见或指定可见资源
5. 用户查看 AI 资源列表或进行 AI 对话时，将按所属分组控制可见和可调用资源

## 卸载说明

- 卸载插件后，建议同步移除 AI 分组相关菜单、权限和数据库表
- 如前端页面或业务流程已依赖 AI 分组能力，请同步清理对应集成
